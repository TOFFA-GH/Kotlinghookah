# Кальянная Карта Зала (Kotlin + Jetpack Compose)

Нативное Android-приложение на **Kotlin (Jetpack Compose)** со всеми 60 столами, разделением на Тёмную кальянную зону и Белую зону (блокировка до 22:00 по системному времени телефона), сохранением состояния столов в памяти устройства (`SharedPreferences`) и живыми таймерами.

## Как собрать `.apk` за 1 минуту:

### Вариант 1: Через Android Studio (на ПК)
1. Распакуйте этот архив.
2. Откройте папку проекта в **Android Studio**.
3. В верхнем меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2: Автоматически в облаке через GitHub Actions (без установки Android Studio)
В проект уже встроен готовый файл `.github/workflows/build-apk.yml`:
1. Загрузите файлы из архива в любой новый репозиторий на GitHub.
2. Перейдите во вкладку **Actions** — сборка запустится автоматически.
3. Через ~2 минуты скачайте готовый `HookahFloorMap-debug-apk` прямо со страницы сборки на телефон.
